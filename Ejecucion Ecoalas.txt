## Comandos para ejecutar el proyecto EcoAlas

### A. Ejecutar el proyecto si ya está instalado

1. Abrir terminal y ubicarse en la carpeta del proyecto:
   cd C:\avesGit\aves-proyecto

2. Ejecutar el backend (servidor de chat):
   npx nodemon backend/server.js

3. En otra terminal, ejecutar el frontend (React con Vite):
   npm run dev

4. Abrir la URL que da Vite en el navegador (por lo general [http://localhost:5173/](http://localhost:5173/)) y usar el chat.

---

### B. Ejecutar el proyecto desde cero (después de descargar de GitHub)

1. Clonar el repositorio:
   git clone <URL-del-repositorio>
   cd <nombre-de-la-carpeta-del-proyecto>

2. Instalar dependencias:
   npm install

3. Verificar instalación de nodemon (opcional):
   npm install --save-dev nodemon

4. Instalar y asegurarse que Ollama esté corriendo:

* Ollama debe estar instalado y levantado antes de usar el chat.
* Abrir Ollama o ejecutar el servidor local de Llama 3 según tu configuración.

5. Ejecutar backend:
   npx nodemon backend/server.js

6. Ejecutar frontend:
   npm run dev

7. Abrir la URL que Vite indique en el navegador y probar el chat.
